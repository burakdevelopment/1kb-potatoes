# 🥔 1KB Potatoes <1KB Chain Reaction Game

An ultra-minimalist, high-performance chain reaction puzzle game built entirely in a single file using pure vanilla HTML5 Canvas, CSS, and JavaScript. 

Created for the **Ultra Hard Mode <1KB** challenge, this project packs a physics-based particle system, dynamic wave propagation, and full game-state management into less than 1 kilobyte of size.

## Features

* **Under 1KB:** Written entirely from scratch without any external libraries, frameworks, bundlers, or build tools.
* **Original Mechanics:** Click to release a limited number of "Pulses" and trigger a cascading chain reaction. Turning raw potatoes 🥔 into fries 🍟 via shockwaves! (hack club waves :D)
* **Pure Vanilla Stack:** Standard HTML, CSS, and JS leveraging the HTML5 Canvas API and requestAnimationFrame.

## How to Play Dude???

1. Copy the code from here (and create html paste into) or download the html.
2. Open index.html in any modern web browser.
3. Click anywhere on the screen to deploy a **Hack Club Pulse Waves** :D.
4. Time your clicks carefully to catch multiple potatoes, trigger secondary explosions, and maximize your score before your pulses run out!

## Tech Stack

* **HTML5 Canvas** Rendering & Physics
* **Vanilla JavaScript** Game Loop & Collision Detection
* **CSS** Zero external dependencies
